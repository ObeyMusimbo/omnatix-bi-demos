{{CARDS}}

An open AI model (Qwen, or Gemma or Nemotron when it is busy) answers from SQL that runs in your browser on each dashboard's own data. Every answer with figures shows its query and rows.

From raw files

CSV exports land as they are. Nothing is corrected by hand. Mixed date formats, duplicate rows, missing costs and orphan product codes are all resolved in the pipeline, visibly.

Tested every build

Bronze, silver and gold layers in dbt, with a test suite that runs on every refresh. A failing test stops the publish, so a number nobody checked never reaches a screen.

No server

Each dashboard runs its own query engine in your browser, with no database to host, which is why these cost almost nothing to keep online. Ask any of them a question and an open AI model answers from SQL you can see, run on that dashboard's own data.

Honest about age

On a client's live data, each dashboard counts the days since its newest transaction, against your clock, and turns red when a feed stops. The four fictional demos cover a fixed period, so their badge tracks the nightly rebuild instead.
