Synthetic data Kestrel Logistics is a fictional operator. Every figure on this page is generated and contains deliberately planted findings. No real company data appears here.

Built by Omnatix. Trip, fuel, workshop and delivery exports land as CSV, are modelled through bronze, silver and gold layers in dbt on DuckDB, tested on every build, and published as Parquet. This page loads those files and runs SQL against them in your browser using DuckDB-WASM. There is no backend and no database server. The map is drawn from coordinates in the data, not from map tiles.

The AI recommendations are written by a language model from the same gold tables, after every rebuild, and each names the model that wrote it. Check them against the figures on screen before acting on them.
