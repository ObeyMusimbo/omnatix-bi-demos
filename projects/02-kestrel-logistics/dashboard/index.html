Synthetic data Kestrel Logistics is a fictional operator. Every figure on this page is generated and contains deliberately planted findings. No real company data appears here.

Built by Omnatix. Trip, fuel, workshop and delivery exports land as CSV, are modelled through bronze, silver and gold layers in dbt on DuckDB, tested on every build, and published as Parquet. This page loads those files and runs SQL against them in your browser using DuckDB-WASM. There is no backend and no database server. The map is drawn from coordinates in the data, not from map tiles, so nothing at all is fetched from a third party.
