Meridian Provisions Co. / FMCG distribution / Gauteng, KwaZulu-Natal, Western Cape /

Starting the query engine

The warehouse is running in your browser. Nothing is being sent to a server.

Synthetic data Meridian Provisions Co. is a fictional business. Every figure on this page is generated and contains deliberately planted findings. No real company data appears here.

Built by Omnatix. Source files land as CSV, are modelled through bronze, silver and gold layers in dbt on DuckDB, tested on every build, and exported to Parquet. This page loads those files directly and runs SQL against them in your browser using DuckDB-WASM. There is no backend, no database server, and no data leaves your machine.

The analyst's notes are written by an AI model from the same gold tables this page reads, after every rebuild, and each one names the model that wrote it. The figures on the page are the ones to check them against. Every build runs the full test suite first: if a test fails nothing is published, and the dashboard keeps serving the last figures that passed.
